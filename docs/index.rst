Miser PV System Optimiser
=========================

Miser is a Home Assistant custom integration that models a PV system, battery,
inverter, tariff and load forecast, then writes scheduled charge or discharge
controls to a supported inverter integration.

The integration is currently focused on Solis inverter systems and
Octopus-style import/export tariffs.
